# ADR 0006：持久结果与执行上下文分离

状态：更新；取代原先完成后保留原 Wire 读取许可的方案。

响应入库时核验原连接来源、完整 binding 和原生结构，按固定 TTL 和 Store 预算保存正文、摘要与句柄。完成后释放执行上下文，结果读取不依赖原连接、permit 或重复 schema 校验，因此断连后仍可读取已经提交的结果。

每次读、打开句柄或显式 discard 核对当前 token 身份、设备范围及调用/结果原主体归属。没有独立 discard 权限，也没有 token permissions 命令。读到 EOF 不删除、不续期；runtime_response_discard 删除原文和句柄，TTL、设备撤销和存储降级仍生效。

回归覆盖真实通道提交后断连取回、完整字节/hash、固定期限、跨主体拒绝、设备范围收窄与 token 吊销、预算及显式清理。合成原生回包不代表真实模型任务完成。
